# 03: Удалить авторизацию стартер-кита

**What to build:** в приложении нет ни входа, ни регистрации, ни профиля, ни dashboard. Гость открывает главную страницу и не видит ссылок на вход и регистрацию. Кода, маршрутов, страниц, тестов, зависимостей и таблиц, связанных с пользователями и авторизацией, в проекте нет. Таблица сессий остаётся, потому что драйвер сессий по умолчанию — база данных. `composer ci:check` зелёный.

**Blocked by:** None (can start immediately)
