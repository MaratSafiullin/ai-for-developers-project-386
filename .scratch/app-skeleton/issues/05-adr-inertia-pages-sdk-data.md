# 05: ADR — страницы через Inertia, данные через SDK

**What to build:** в `docs/adr/` лежит первый ADR. Он объясняет, почему страницы рендерит Inertia (с Wayfinder для навигации), а данные страницы получают через клиентский SDK, сгенерированный из контракта TypeSpec → OpenAPI.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] ADR короткий: статус, контекст (клиентский SDK обязателен по условию учебного проекта, стартер-кит построен на Inertia), решение, последствия
- [ ] Перечислены отвергнутые варианты и причины: чистое SPA без Inertia (пришлось бы выбросить готовую маршрутизацию и лейауты стартер-кита) и только Inertia props без SDK (нарушает требование про SDK)
- [ ] Указано, что JSON API и подключение API-маршрутов появятся на шаге контракта
- [ ] Коммит в формате Conventional Commits (например, `docs: add ADR for inertia pages with sdk data`)
