# Страницы через Inertia, данные через SDK

**Статус:** принято, 2026-10-28

## Контекст

По условию учебного проекта фронтенд работает с данными через клиентский SDK, сгенерированный из контракта API: TypeSpec → OpenAPI → SDK.

Проект создан из Laravel React Starter Kit, а он построен на Inertia: Laravel-маршрут отдаёт React-страницу, Wayfinder генерирует TypeScript-функции для маршрутов, сборка Vite+ уже настроена. В чистом виде Inertia передаёт данные страницы как props и отдельного JSON API не предполагает.

## Решение

Гибрид:

- **Страницы рендерит Inertia.** Маршруты страниц описаны в `routes/web.php`, переходы между страницами идут через функции Wayfinder.
- **Данные страницы получают через SDK** к JSON API, описанному в контракте.

JSON API и подключение API-маршрутов появятся на шаге контракта. В каркасе их нет.

## Отвергнутые варианты

- **Чистое SPA без Inertia** (клиентский роутер + SDK). Пришлось бы выбросить готовую связку Laravel-маршрутов, Inertia и Wayfinder и написать маршрутизацию на клиенте заново.
- **Только Inertia props без SDK.** Проще всего, но нарушает обязательное требование про клиентский SDK.

## Последствия

- У бэкенда два вида маршрутов: страницы через Inertia и JSON API для SDK.
- Какие данные страница получает через props, а какие через SDK, решается на шаге контракта.
